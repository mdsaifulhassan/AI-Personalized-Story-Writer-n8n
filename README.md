# AI Personalized Story Writer (n8n)

An n8n workflow that collects story details through a form and writes a personalized story with OpenAI.

## Features
- Custom form with banner, mobile-friendly styling
- Genre, mood, audience, ending, length and language options
- Bangla and English stories

## How to use
1. In n8n, click **Import from file** and select `story-writer-workflow.json`
2. Add your own OpenAI credentials
3. Publish the workflow and open the Production URL of the form

## Files
- `story-writer-workflow.json`: the n8n workflow
- `form-styles.css`: custom styling for the form
